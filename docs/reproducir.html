Reproducir los resultados

No todo cuesta lo mismo de comprobar. Esta página separa lo que se verifica clonando el repositorio de lo que exige la base de datos o los modelos, para que nadie pierda el tiempo averiguándolo por su cuenta.

Nivel 1 · Leer una cifra

Las métricas publicadas son ficheros JSON. Comprobar que una tabla de la memoria coincide con su fuente es leer un fichero.

git clone https://github.com/819524/rag-clinico-tfm.git
cd rag-clinico-tfm

python3 -c "
import json
m = json.load(open('experimentos/1-recuperacion-por-documento/resultados/embedding-4b/section_metrics_summary.json'))
print({k: v for k, v in m['strategies']['cross_encoder'].items() if k.startswith('sec@0.7')})"

Nivel 2 · Recalcular sin instalar nada

El experimento 4 se reproduce entero: opera sobre las respuestas ya registradas, sin base de datos ni modelos.

python3 herramientas/eval_gen_quality.py

Debe imprimir exactamente la tabla de metricas.txt. Los agregados sobre las tablas de carga también se recalculan con la biblioteca estándar:

python3 -c "
import csv, statistics as st
from collections import defaultdict
p = defaultdict(list)
for f in csv.DictReader(open('experimentos/5-carga-y-motores/barridos.csv')):
    if f['motor'] and f['concurrencia'] == '10':
        p[f['motor']].append(float(f['tiempo_muro_ms']))
for m, v in sorted(p.items()):
    print(f'{m:10} mediana {st.median(v)/1000:6.1f} s  (n={len(v)})')"

Nivel 3 · El límite real

Las métricas de recuperación no pueden recalcularse con lo publicado. herramientas/eval_section_metrics.py decide si un fragmento recuperado es relevante comparando la cita de referencia contra el texto completo de su sección, que consulta en la base de datos. Ese texto es el corpus del hospital y no se redistribuye, así que la relevancia no puede reconstruirse desde los resultados.

Sin la base de datos sí puede verificarse: que las tablas de la memoria coinciden con section_metrics_summary.json; que los documentos recuperados y su orden son los que declaran los resultados; y que los conjuntos de preguntas contienen las citas que dicen contener.

Lo mismo ocurre, por motivos distintos, con el cortafuegos: su script invoca el router, el recuperador y el generador del sistema completo, de modo que se publica como documentación exacta del método, no como herramienta ejecutable.

Un hueco que conviene declarar

La tabla del §4 del documento de trazabilidad —el efecto de las correcciones de etiquetado sobre las métricas publicadas— se calculó con un script de un solo uso que no forma parte del repositorio. Sus cifras están declaradas, pero no son regenerables desde aquí. Se señala en vez de dejar que parezca reproducible.

Diferencias esperables al reejecutar

  • La generación no es determinista aunque la temperatura sea baja: el texto de las respuestas variará entre ejecuciones.
  • Las métricas de recuperación sí son deterministas dado el mismo índice y el mismo modelo de embedding.
  • Los tiempos dependen del hardware; los publicados corresponden a las máquinas descritas en el experimento 5.
  • Las ejecuciones publicadas proceden de la campaña original y no se han reejecutado al preparar este repositorio.
